# Functional pilot preparation revisions

No student inference or training was run during these revisions.

The first candidate preparation had syntax, data-shape, indentation and file-identity problems. These were corrected before the authoritative container checks. Related HTML and CSV normalized contexts were assigned together in training. The page-selection family was assigned to development instead. All variants of each family retain the same assignment.

CPU qualification v2 passed all 192 gold actions and all 192 behavior-breaking controls using the existing pinned Python 3.12 OCI image with networking disabled. Host preparation runs Python 3.11. V2 remains a diagnostic artifact and will not enter training.

V3 adds an explicit function contract to the current source and changes deletion history. The most recent synthetic edit now establishes the required transformation; the deletion removes an older obsolete effect and preserves that latest edit. This avoids training every deletion as a reversal of the latest edit. The new plan freezes the changed states before rerunning all gold and wrong controls. V1 was an unexecuted preparation plan.

These are deliberately authored examples, not observed human edit sequences. Functional success on their fixtures does not establish general next-edit quality. Public source-prefix literal accuracy has a separate denominator.
