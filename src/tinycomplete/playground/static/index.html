Private by design

      
This page talks only to 127.0.0.1 on your machine (GET /api/models, POST /api/complete, POST /api/feedback). No CDN, no fonts, no analytics. Code and feedback never leave the laptop; the model runs locally via the playground server.

      
Tip: open DevTools → Network to confirm every request goes to localhost.
